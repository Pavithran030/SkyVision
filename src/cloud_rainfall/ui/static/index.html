    ℹ️ Scientific Foundations & Meteorological Constraints

    Understanding machine vision limitations when applied to precipitation nowcasting.

    1. The Critical Atmospheric Limitation

    A ground-based sky camera captures optical bottom scattering and visible cloud morphology. However, true precipitation physics depend on total precipitable water, vertical cloud thickness, cloud condensation nuclei, and upper-air thermal updrafts not visible from a single 2D ground image. Therefore, training a cloud classifier does not automatically yield a reliable rainfall estimator.

    2. Decoupling Task A and Task B

    Our architecture maintains strict separation between Task A (Cloud Recognition) and Task B (Rainfall Estimation). Visual features (1024-D embeddings) are extracted from the CNN and fed to dedicated estimators trained on timestamp-aligned rainfall targets.

    3. Strict Prevention of Temporal Leakage

    To avoid leaking information between frames, all splits are date-aware (storm-aware). Consecutive photos from the same weather system stay together in the same split. Furthermore, all model inputs are strictly at or before image capture time $t$, and the rainfall prediction is explicitly evaluated on $[t, t+1\text{ hour})$.

    4. Prototype Label Provenance

    When physical on-site rain gauges are unavailable, Open-Meteo reanalysis/model data provides a valuable research proxy. Our interface transparently marks these predictions with a proxy-label experiment badge, preventing false claims of gauge-calibrated accuracy.
